[시스템 접속 - 윤리 서약]

⚠️ 주의: 본 시뮬레이션은 정당하게 허가된 환경에서만 수행되어야 합니다.

[LEVEL 1: 로그인 우회]

가상의 보안 서버 관리자 로그인 인증 페이지입니다. 인증 로직을 우회하여 관리자 권한을 획득하세요.

💡 힌트: 내부 SQL 쿼리가 무조건 **참(True)**이 되도록 만드세요.
예: ' OR '1'='1 또는 " OR "1"="1

[LEVEL 2: 스크립트 삽입]

게시판 검색 시스템의 입력값 검증 취약점을 이용해 악성 자바스크립트를 실행시키세요.

💡 힌트: 브라우저에 알림창(alert)을 띄우는 스크립트 태그를 입력창에 직접 삽입하세요.
예: <script>alert(1)</script>

[LEVEL 3: 숨겨진 요소 찾기]

관리자 제어판으로 진입하려 했으나 화면에 아무런 조작 버튼이 보이지 않습니다.

💡 힌트: 관리자 전용 [시스템 장악] 버튼이 클라이언트 코드에 숨겨져 있습니다.
**개발자 도구 (F12)**를 열어 소스코드를 검사하고, display: none 스타일을 제거한 후 버튼을 클릭하세요!
[ 영역: 숨겨진 오브젝트 ]

[MISSION ACCOMPLISHED]

🎉 축하합니다! 당신은 훌륭한 화이트해커의 자질을 갖추었습니다.

1. SQL Injection (SQL 삽입)

사용자 입력값을 검증하지 않고 쿼리문에 직렬화할 때 발생합니다. Prepared Statement(파라미터화된 쿼리)를 사용하여 예방해야 합니다.

2. Reflected XSS (크로스 사이트 스크립팅)

검증되지 않은 입력값이 브라우저에서 HTML/JS로 실행되는 취약점입니다. 입출력 시 HTML 엔티티 치환(Escaping) 처리가 필수적입니다.

3. DOM & Client-side Manipulation (클라이언트 조작)

클라이언트 측(HTML/JS/CSS)의 은닉 처리나 검증은 사용자에 의해 손쉽게 조작될 수 있습니다. 중요 로직은 반드시 서버 측에서 검증해야 합니다.
