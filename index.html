Level 01 · Auth Bypass

로그인 인증을 우회하세요

가상 보안 서버의 관리자 로그인 페이지입니다. 인증 로직을 우회해 관리자 권한을 획득하세요.

💡 hint
내부 SQL 쿼리가 무조건 참(True)이 되도록 조건을 주입하세요.
예: ' OR '1'='1 또는 " OR "1"="1
Level 02 · Script Injection

검색창에 스크립트를 실행시키세요

게시판 검색 기능의 입력값 검증 취약점을 이용해 악성 자바스크립트를 브라우저에서 실행시키세요.

💡 hint
알림창(alert)을 띄우는 스크립트 태그를 검색어에 그대로 넣으세요.
예: <script>alert(1)</script>
Level 03 · Hidden Element

숨겨진 제어 버튼을 찾으세요

관리자 제어판에 진입하려 했으나 화면에 아무 버튼도 보이지 않습니다. 클라이언트 코드 안에는 남아 있습니다.

💡 hint
관리자 전용 시스템 장악 버튼이 코드에 숨겨져 있습니다. 개발자 도구(F12)를 열어 소스를 검사하고 display: none 을 제거한 뒤 버튼을 누르세요.
영역: 숨겨진 오브젝트
Mission · Accomplished

전 구간 침투 성공

🎉 축하합니다. 화이트해커의 자질을 갖췄습니다.

01

SQL Injection · SQL 삽입

사용자 입력을 검증 없이 쿼리에 이어 붙일 때 발생합니다. Prepared Statement(파라미터화된 쿼리)로 값과 코드를 분리해 예방합니다.

02

Reflected XSS · 크로스 사이트 스크립팅

검증되지 않은 입력이 브라우저에서 HTML·JS로 실행되는 취약점입니다. 출력 시 HTML 엔티티 치환(Escaping)이 필수입니다.

03

Client-Side Manipulation · 클라이언트 조작

클라이언트(HTML·JS·CSS)의 은닉이나 검증은 사용자가 손쉽게 바꿀 수 있습니다. 중요한 로직은 반드시 서버에서 검증합니다.
